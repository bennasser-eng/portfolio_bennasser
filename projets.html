AgriGuard-RAG — Assistant Réglementaire Phytosanitaire

Agentic RAG | NLP | LLM

Système RAG hybride et agentique pour l'interrogation de la réglementation phytosanitaire française (E-Phy), indexant 5 277 fiches officielles.

  • Routage d'intention dynamique : Classification hybride (heuristiques + TF-IDF / Logistic Regression) pour aiguiller les requêtes simples ou complexes.
  • Recherche hybride & Fusion RRF : Indexation vectorielle sur Qdrant Cloud associant embeddings denses (FastEmbed) et sparse (BM25) avec reclassement par Reciprocal Rank Fusion et filtrage par métadonnées (AMM, culture).
  • Agent de raisonnement (Agentic RAG) : Décomposition automatique de requêtes complexes en sous-problèmes indépendants, extraction parallèle et synthèse sans hallucination via l'API Groq Cloud.
  • Mise en production : Déploiement cloud sécurisé (gestion des secrets, gestion du cache mémoire et interface de dialogue interactive).
  • Python

  • Groq API
  • FastEmbed
